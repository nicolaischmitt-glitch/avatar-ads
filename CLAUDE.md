# Avatar Ads 1.0

Proyecto de Avatar Ads 1.0: curso/programa con todo el contenido, sistemas y herramientas para producir contenido y anuncios UGC hiperrealistas con IA. Los talleres en vivo son solo un mecanismo de marketing para venderlo. Aquí se crean la landing, los anuncios, los reels de Instagram y el contenido del programa.

Antes de crear cualquier contenido, guion, anuncio, caption o material del curso, básate en estos dos documentos (se cargan siempre):

- Datos del proyecto, oferta, branding y estructura de carpetas: @PROYECTO.md
- Ángulos de venta, público, dolores, objeciones, mensajes clave y tono: @BASE-CONOCIMIENTO.md

Reglas:
- Responde en español.
- No inventes datos (precios futuros, testimonios, métricas, fechas). Si falta uno, pregunta.
- Reels de Instagram y anuncios en video → skill `reels-avatar-ads` (anuncio head talking de una toma + B-rolls → `skills/reels-avatar-ads/formatos/head-talking/LEEME.md`). Carruseles de Instagram → skill `carruseles-avatar-ads`. Cualquier copy (títulos y secciones de la landing, hooks y guiones de anuncios, texto de Meta Ads, emails, captions, DMs) → skill `copy-avatar-ads` (guarda lo aprobado en `skills/copy-avatar-ads/banco-aprobado.md`). Landing pages, páginas de venta y de gracias (de Avatar Ads o de cualquier otro producto) → skill `paginas-de-venta`. Prompts JSON de Google Flow → `skills/master prompt para json prompts videos.txt`. Prompts JSON de imágenes hiperrealistas (frame del avatar desde cero, Nano Banana) → `skills/master prompt para json prompts imagenes.md`.
- El producto que se enseña y se vende es el **Sistema Avatar Ads** (`sistema-avatar-ads/`, ver su `LEEME.md` y `PROYECTO.md`). Cada formato o mejora que probemos en nuestros anuncios se lleva también al kit.
- Si se decide algo nuevo sobre la oferta o el marketing, actualiza `PROYECTO.md` o `BASE-CONOCIMIENTO.md` según corresponda.
