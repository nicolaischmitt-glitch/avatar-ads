# Avatar Ads 1.0

Proyecto de Avatar Ads 1.0: curso/programa con todo el contenido, sistemas y herramientas para producir contenido y anuncios UGC hiperrealistas con IA. Los talleres en vivo son solo un mecanismo de marketing para venderlo. Aquí se crean la landing, los anuncios, los reels de Instagram y el contenido del programa.

Antes de crear cualquier contenido, guion, anuncio, caption o material del curso, básate en estos dos documentos (se cargan siempre):

- Datos del proyecto, oferta, branding y estructura de carpetas: @PROYECTO.md
- Ángulos de venta, público, dolores, objeciones, mensajes clave y tono: @BASE-CONOCIMIENTO.md

Reglas:
- Responde en español.
- No inventes datos (precios futuros, testimonios, métricas, fechas). Si falta uno, pregunta.
- Reels de Instagram → skill `reels-avatar-ads`. Carruseles de Instagram → skill `carruseles-avatar-ads`. Prompts JSON de Google Flow → `skills e instrucciones/master prompt para json prompts videos.txt`.
- Si se decide algo nuevo sobre la oferta o el marketing, actualiza `PROYECTO.md` o `BASE-CONOCIMIENTO.md` según corresponda.
